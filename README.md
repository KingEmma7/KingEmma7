## Selected engineering work

### [psbt-guard](https://github.com/KingEmma7/psbt-guard) · Rust

An offline, read-only verifier for checking whether a Bitcoin PSBT matches the
payment intent a user declares before signing. It is deliberately unable to load
private keys, sign, broadcast, or make network requests. Current status: milestone
M1; intent verification is planned for M2.

### [cursor-os](https://github.com/KingEmma7/cursor-os) · JavaScript

An installable operating layer that makes Cursor project-aware through durable
repository memory, engineering rules, decision logs, reusable workflows, and an
independent verifier. Built to reduce repeated context-setting and make AI-assisted
changes easier to review.

### [Kemma Technologies](https://github.com/KingEmma7/kemma-technologies) · TypeScript

The public home of my product and software engineering practice. Most commercial
repositories remain private by design; I publish architecture and outcomes only
when client confidentiality and user privacy allow it.
